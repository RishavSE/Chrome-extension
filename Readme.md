<h2 align="center">📌 Overview</h2>

AI Web Page Summarizer is a lightweight Chrome Extension that extracts the content of the currently opened webpage and generates intelligent summaries using the Google Gemini API.

Instead of spending time reading lengthy articles, blogs, documentation, or news pages, users can generate concise AI-powered summaries in seconds directly from their browser.

<h2 align="center">🤖 AI Summary Modes</h2>

The extension provides three different summarization options based on the user's preference.

### 📝 Short Summary

• Generates a concise overview of the webpage.

• Ideal for quick understanding.

---

### 📄 Detailed Summary

• Produces a comprehensive explanation covering the important concepts and context.

• Best for studying articles or documentation.

---

### 📌 Bullet Point Summary

• Converts the webpage into easy-to-read bullet points.

• Perfect for revision and quick scanning.

<h2 align="center">🚀 Installation</h2>

1. Clone the repository

```bash
git clone https://github.com/RishavSE/Chrome-extension.git
```

2. Open Chrome

3. Navigate to

```
chrome://extensions/
```

4. Enable **Developer Mode**

5. Click **Load Unpacked**

6. Select the project folder

7. Open any webpage and start generating AI-powered summaries.
